                                          Quick overview
<-------------------------------------------------------------------------------------->
1) Prepare project folder:
    
    D:\GrainPalette\
 ├─ train_mobilenetv2.py        # training script (the one I gave)
 ├─ build_model.py              # optional
 ├─ app.py                      # Streamlit app
 ├─ rice_dataset\               # dataset folder (see structure below)
 └─ requirements.txt            # pip requirements (optional)

<-------------------------------------------------------------------------------------->
2) Create & activate Python environment
      cd D:\GrainPalette

# create venv (only once)
python -m venv rice-env

# activate (PowerShell)
& D:/GrainPalette/rice-env/Scripts/Activate.ps1
# prompt should show (rice-env)
<-------------------------------------------------------------------------------------->
3)Install dependencies
         Create requirements.txt containing (example):

tensorflow
numpy
pillow
matplotlib
pandas
scikit-learn
seaborn
streamlit


Install:

pip install --upgrade pip
pip install -r requirements.txt


If you don’t use requirements.txt, install directly:

pip install tensorflow numpy pillow matplotlib pandas scikit-learn seaborn streamlit


Tip: On CPU-only Windows, TensorFlow can be slow. Use Google Colab (GPU) if training is slow.
<-------------------------------------------------------------------------------------->
4) Train the model (Transfer Learning MobileNetV2)
             python train_mobilenetv2.py
<-------------------------------------------------------------------------------------->
5) Inspect training results
            After training, open these files:

            accuracy.png and loss.png — training/validation curves.

            classification_report.txt — precision/recall/F1 per class.

            confusion_matrix.png — confusion matrix heatmap (if seaborn installed).

            misclassified.csv — rows: filename,true_label,pred_label,pred_confidence.

Y           ou can open CSV in Excel or VSCode.
<-------------------------------------------------------------------------------------->
6) Run the Streamlit app (prediction UI)
        streamlit run app.py
<-------------------------------------------------------------------------------------->
7) Commands checklist (copy-paste friendly)
            # in PowerShell
cd D:\GrainPalette
& D:/GrainPalette/rice-env/Scripts/Activate.ps1
pip install -r requirements.txt     # or pip install ...
python train_mobilenetv2.py
# after training:
streamlit run app.py
